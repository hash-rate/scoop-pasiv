# Pasiv — Scoop bucket

```powershell
scoop bucket add pasiv https://github.com/hash-rate/scoop-pasiv
scoop install pasiv
```

[Pasiv](https://pasiv.network) is a non-custodial desktop miner: the mining pool
pays your own wallet directly, and the app holds no funds and never asks for
keys. It mines nothing until you press Start.

- What the 4% fee is, and the address you can audit it at: https://pasiv.network/teams
- Other install methods: https://pasiv.network/install
